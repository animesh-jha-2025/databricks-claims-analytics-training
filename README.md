# Databricks for Claims Analytics: hands-on training

Two 2-hour, instructor-led sessions for analysts who work with **de-identified pharmacy and medical claims**. Everything runs on **[Databricks Free Edition](https://www.databricks.com/learn/free-edition)** with a small **synthetic** dataset. No company data or company workspace access is needed.

> 🔒 All data in this repo is **synthetic**: it's generated by `00_Setup/00_Generate_Synthetic_Data`. No real members, providers, or clients appear.

## Setup (do this before Session 1, about 10 minutes)

### 1. Create a free Databricks account
1. Go to **https://www.databricks.com/learn/free-edition** → **Sign up for Free Edition**.
2. Sign up with your email (a personal or work email both work), then verify it.
3. You'll land in your own workspace. Bookmark it.

### 2. Import this repo
**Option A: Git folder (recommended)**
1. In the left sidebar, click **Workspace** → open your home folder.
2. Click **Create** → **Git folder**.
3. Paste the repo URL: `https://github.com/<OWNER>/databricks-claims-analytics-training` → **Create Git folder**.

**Option B: ZIP fallback (if GitHub is blocked on your network)**
1. Download `databricks-claims-analytics-training.dbc` from the **Releases** page of this repo (or the file your instructor emailed you).
2. In **Workspace** → your home folder → **⋮** → **Import** → **File** → drop the `.dbc` file → **Import**.

### 3. Generate the data
1. Open `00_Setup/00_Generate_Synthetic_Data`.
2. Click **Connect** (top right) → **Serverless**.
3. Click **Run all**. It takes about 1–2 minutes.
4. Check that the last cell lists **8 tables** in `workspace.claims_training`.

✅ **You're ready.** If anything fails, take a screenshot and send it to your instructor before the session.

## Notes
* All notebooks use two widgets, `catalog` (default `workspace`) and `schema` (default `claims_training`). You only need to change them if you run this outside Free Edition.
* Free Edition is for learning only. It has daily compute limits and is not for company or member data.
* Notebook 08 has one cell that **fails on purpose**. It's used to demo the Assistant's `/fix`.
